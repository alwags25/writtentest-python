FastAPI 流式 API 演示

纯文本、SSE、NDJSON 与模拟 LLM 聊天，全部基于 StreamingResponse + 异步生成器。

就绪

1. 纯文本流 GET /api/stream/plain

以 text/plain 逐片段返回文字，演示最基础的流式响应。

点击“开始接收”查看逐段到达的文本…

2. SSE 进度 GET /api/stream/sse

Server-Sent Events 推送带事件名的 JSON，浏览器用 EventSource 订阅。

等待 progress / done 事件…

3. NDJSON GET /api/stream/ndjson

每行一条 JSON 记录，适合日志、数据导出等场景。

等待 JSON 记录逐行到达…

4. 模拟 LLM 聊天 POST /api/chat/stream

EventSource 只支持 GET，所以这里用 fetch + ReadableStream 解析 SSE，逐 token 显示。

等待提问…
